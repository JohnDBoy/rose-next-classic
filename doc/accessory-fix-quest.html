=== ROSE Accessory Fix Quick Reference ===

PROBLEM: Server crashes when players have accessories in slots 9-11

SOLUTION 1 - Database (Quick):
UPDATE inventory SET slot = slot + 100 WHERE slot IN (9, 10, 11);

SOLUTION 2 - Code Patch (Permanent):
In datatype.h line 934: Change EQUIP_IDX_WEAPON_L to EQUIP_IDX_EARRING

PREVENTION: Add trigger to auto-move future accessories:
CREATE TRIGGER prevent_accessory_slots BEFORE INSERT ON inventory
FOR EACH ROW WHEN (NEW.slot IN (9,10,11)) 
BEGIN NEW.slot := NEW.slot + 100; END;

Remember: Always backup before making changes!
